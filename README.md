# TrueWish Telegram Bot

Telegram бот для управления курсами с материалами (видео, аудио) и практическими заданиями.

## 🚀 Возможности

### Для пользователей:
- 📚 Доступ к курсам по темам
- 🎥 Просмотр видео и аудио материалов
- ✍️ Выполнение практических заданий
- 📊 Отслеживание прогресса
- ✅ Индикация завершенных тем

### Для администраторов:
- 👥 Управление пользователями
- 🔑 Предоставление доступа к темам
- 📝 Создание и редактирование материалов
- 💬 Просмотр ответов пользователей
- ✅ Проверка и подтверждение заданий

## 📋 Требования

- Node.js >= 16.x
- npm или yarn
- Telegram Bot Token (от @BotFather)

## 🛠 Установка

1. **Клонируйте репозиторий или создайте проект:**
```bash
cd trueWish
```

2. **Установите зависимости:**
```bash
npm install
```

3. **Создайте файл `.env` на основе `.env.example`:**
```bash
cp .env.example .env
```

4. **Настройте `.env` файл:**
```env
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_PORT=3000
ADMIN_PASSWORD=ваш_пароль_админки
DB_PATH=./database.sqlite
NODE_ENV=production
```

5. **Настройте `config.json`:**
Добавьте список администраторов и настройки бота в файл `config.json`.

6. **Инициализируйте базу данных:**
```bash
npm run db:init
```

## 🚀 Запуск

### Режим разработки:
```bash
npm run dev
```

### Режим production:
```bash
npm start
```

### С использованием PM2 (рекомендуется для production):
```bash
# Запуск
npm run pm2:start

# Просмотр логов
npm run pm2:logs

# Перезапуск
npm run pm2:restart

# Остановка
npm run pm2:stop
```

После запуска:
- 🤖 Telegram бот будет активен
- 🌐 Админ-панель доступна по адресу: `http://localhost:3000`

## 📖 Использование

### Для пользователей

1. Найдите вашего бота в Telegram
2. Отправьте команду `/start`
3. Если у вас есть доступ, появится список доступных тем
4. Выберите тему для изучения
5. Просматривайте материалы и выполняйте задания
6. Ваш прогресс сохраняется автоматически

### Для администраторов

1. Откройте админ-панель: `http://localhost:3000`
2. Войдите с паролем из `.env`
3. **Создайте темы:**
   - Перейдите в раздел "Темы"
   - Нажмите "Добавить тему"
   - Заполните название, описание и порядок
4. **Добавьте материалы:**
   - Откройте нужную тему
   - Нажмите "Материалы"
   - Добавьте видео/аудио/текст и практические задания
5. **Управляйте пользователями:**
   - В разделе "Пользователи" выберите пользователя
   - Отметьте галочками доступные ему темы
   - Просматривайте ответы на задания
   - Отмечайте выполненные задания

## 🗂 Структура проекта

```
trueWish/
├── src/
│   ├── bot.js              # Логика Telegram бота (Telegraf)
│   ├── admin.js            # Админ-панель (Express)
│   ├── index.js            # Точка входа
│   ├── database/
│   │   ├── db.js           # Подключение к БД
│   │   ├── models.js       # Модели данных
│   │   └── init.js         # Инициализация БД
│   └── views/              # EJS шаблоны админки
│       ├── login.ejs
│       ├── users.ejs
│       ├── user-detail.ejs
│       ├── topics.ejs
│       └── materials.ejs
├── config.json             # Конфигурация (администраторы)
├── .env                    # Переменные окружения
├── ecosystem.config.js     # Конфигурация PM2
└── package.json
```

## 🗄 Структура базы данных

- **users** - пользователи бота
- **topics** - темы курса
- **materials** - материалы (видео/аудио/текст) с заданиями
- **user_topic_access** - доступы пользователей к темам
- **user_progress** - прогресс пользователей
- **user_answers** - ответы на задания

## 🔒 Безопасность

- Пароль админ-панели хранится в виде bcrypt-хэша
- Сессии с защитой
- Валидация доступов на уровне БД
- Graceful shutdown для корректной остановки

## 📝 Получение File ID для видео/аудио

Чтобы добавить видео или аудио файл:

1. Отправьте файл вашему боту в Telegram
2. Временно добавьте логирование в `src/bot.js`:
```javascript
this.bot.on('message', (ctx) => {
  console.log('Message:', ctx.message);
});
```
3. В логах найдите `file_id`
4. Скопируйте его и добавьте в материал через админку

## 🐛 Отладка

Просмотр логов PM2:
```bash
pm2 logs truewish-bot
```

Просмотр ошибок:
```bash
pm2 logs truewish-bot --err
```

## 📦 Резервное копирование

База данных SQLite хранится в файле `database.sqlite`. Регулярно создавайте его резервные копии:
```bash
cp database.sqlite database.backup.sqlite
```

## 🔄 Обновление

1. Остановите приложение
2. Обновите код
3. Установите новые зависимости: `npm install`
4. Перезапустите: `npm run pm2:restart`

## 🆘 Помощь

При возникновении проблем:
1. Проверьте логи: `npm run pm2:logs`
2. Убедитесь, что `.env` настроен правильно
3. Проверьте, что база данных инициализирована
4. Убедитесь, что токен бота валиден
